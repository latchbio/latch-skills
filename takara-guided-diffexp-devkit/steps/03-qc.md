# Stage 3 — Perform and review QC

Create a tab named exactly:

```
3. Quality Check
```

Announce it in chat by that name. Say it again when the QC outputs land in it —
the user is most likely still looking at **2. Sample Groups**, and the
notebook will not move them.

## Cell template

```python
from lplots.widgets.button import w_button
from lplots.widgets.workflow import w_workflow

qc = w_workflow(
    label="Run sample quality check",
    wf_name="takara_de_qc.workflow.qc",
    params={
        "counts_file": "{{RUN_DIR}}/confirmed/counts.csv",
        "coldata_file": "{{RUN_DIR}}/confirmed/coldata_confirmed.csv",
        "run_dir": "{{RUN_DIR}}",
    },
    automatic=True,
    key="qc_launch",
)
```

Then a **separate** resume cell that reads the outputs — see `wf/qc_wf.md`.

`min_row_sum` is omitted so the workflow default of 10 applies. If the user asks
to change it, say in chat that you are moving it off its default of 10 before
launching.

## What to show

Render `pca.png` and `sample_correlation.png` with `w_plot`, then report from
`qc_metrics.json`:

- `pc1_var` and `pc2_var`;
- the flagged-sample list, using the same rule as stage 2 — a sample whose
  single highest correlation is to a sample in the other condition group.

**This PCA is the authoritative one.** It is a variance-stabilised transform
computed by DESeq2, unlike the rank-correlation map in stage 2. If the two
disagree, trust this one and say so.

**Nothing is ever removed automatically.** Flagging is advisory. The user's
options are: re-upload a corrected file, go back and regroup, or proceed.

## Gate

Cheap gate; ambiguity resolves toward proceeding.

- Confirmed → `steps/04-deseq2.md`.
- The user wants to regroup → return to `steps/02-groups.md`, and QC re-runs
  afterwards.
- The QC workflow failed → the stage does not advance. Show the error, reopen
  the stage 2 gate, offer a retry.
